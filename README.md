My project is called Personal Subscription Spend Auditor, or simply Subscription Spend Tracker.

The Problem:
Nowadays, we buy a lot of subscriptions for different purposes, whether it is for our entertainment, such as movie streaming platforms, or for online shopping.
Subscriptions have become very necessary in our day-to-day lives. However, a lot of times, we can overspend on these subscriptions if we do not keep track of them.

That's where our website, Subscription Spend Tracker, comes into play.

Our Solution:
It can help you keep track of your subscriptions and see how much you are spending monthly and yearly on those subscriptions.
Not only that, it can also group different subscriptions into particular categories and help you identify if you have multiple subscriptions in the same category.
It then suggests that you review whether you really need all of those subscriptions, thus helping you save money as well.

Technologies Used:
The technologies used in this website are:
Python
Flask
HTML
CSS
Jinja2

The main part of the backend of our website is written in Python. Python holds the core functions and logic of the website, while HTML and CSS make up the frontend of the website.

Flask helps connect my Python backend with the HTML and CSS frontend and handles requests from the website.

Jinja2 helps dynamically insert data from my Python backend into the HTML pages, such as the user's subscriptions and their total spending.

I have also used CSS for styling purposes, to make the website look more visually appealing and responsive.


So overall, our goal is to make subscription spending easier to track, help users identify unnecessary overlapping subscriptions, and ultimately help them make better decisions with their money. Thank you.
